Постановка задачи оптимизации и система Лагранжа (**)

По материалам лекций кафедры РК6 (слайды 27–32): принцип наименьших изменений и аналитическая матрица Якоби

n = 0 параметров, m = 0 уравнений
Целевая функция Лагранжа (слайд 27, 30):
F(Δp₁,…,Δpₙ, λ₁,…,λₘ) = ½ ∑ᵢ₌₁ⁿ Δpᵢ² + ∑ⱼ₌₁ᵐ λⱼ fⱼ(p₁+Δp₁,…,pₙ+Δpₙ) → min
Принцип наименьших изменений гарантирует однозначное решение даже для недоопределенных эскизов (при перетаскивании узлов мышью).
Система уравнений (**) и шаг Ньютона (слайды 31–32):
∂F/∂λⱼ = fⱼ(p + Δp) = 0,   j = 1..m
∂F/∂Δpᵢ = Δpᵢ + ∑ⱼ₌₁ᵐ λⱼ (∂fⱼ / ∂Δpᵢ) = 0,   i = 1..n
Все частные производные ∂fⱼ/∂Δpᵢ и ∂²fⱼ/∂Δpᵢ∂Δpₖ вычисляются строго по аналитическим формулам, зашитым в код.

Аналитические выражения уравнений и частных производных активного эскиза

Матрица Якоби СЛАУ A · [Δp, λ]ᵀ = b (решаемая в `CoreAlgo::solve(A, b)`)

Полная блочная матрица ККТ/Якоби размера (m + n) × (m + n) и вектор правой части

Архитектура программного комплекса (по схеме бригады)

Полное соответствие предоставленной архитектурной диаграмме: разделение на Backend (C++17 / Emscripten WASM) и Visualization (JS), включая `Geom Repository`, `Helper Functions (query)`, `Geom Solver`, `Core Algo` и `UseCases`.

1. Backend: Хранение и запросы
Geom Repository (`GeomRepository.hpp`)
  • • Geom = Figure[]: полиморфный базовый класс Figure с методом params() и наследники PointFigure, SegmentFigure
  • • Restrictions: контейнер наложенных ограничений
  • • serializer JSON: сериализация и импорт эскиза в JSON
Helper Functions (`HelperFunctions.hpp`)
  • • queryPointAt(x, y) / querySegmentAt(x, y): геометрический поиск объектов под курсором
  • • computeDOF(): подсчет степеней свободы эскиза
2. Математическое ядро (WASM)
Geom Solver (`GeomSolver.hpp`)
  • • solve(geom, restrictions, new_restrictions) → new_geom
  • • Сборка вектора варьируемых координат и аналитических производных для всех 9 типов ограничений
Core Algo (`CoreAlgo.hpp` + `.wasm`)
  • • solve(A, b): собственный метод Гаусса с выбором главного элемента по столбцу и регуляризацией Тихонова (без сторонних библиотек)
  • • optimize(f, df, params): итерационный метод Ньютона для системы Лагранжа (**)
3. UseCases, API Handler & JS UI
UseCases & API Handler (`UseCases.hpp`)
  • • Render Usecase: getAllPrimitives() → [{point}, {line}]
  • • Tool_1 Usecase: создание/удаление примитивов и 9 ограничений
  • • Pointer Usecase: захват и перетаскивание узлов с пересчетом в реальном времени
Visualization (JavaScript)
  • • Браузер ограничений, Рабочее поле, Панель инструментов
